# Spec Delta: solveability (R3)

## Purpose
Консервативная классификация выполнимости: отсекать только доказуемо невозможные задачи и оставлять сомнительные кандидатами planner.

## ADDED Requirements

### Requirement: Три вердикта с evidence
Проверка выполнимости MUST возвращать одно из состояний `solvable`, `uncertain`, `impossible`. Каждый вердикт MUST содержать `reason_code`, краткое объяснение и evidence. Проверка MUST быть детерминированной при одинаковых task, evidence и config и MUST NOT обращаться в сеть.

#### Scenario: Поддерживаемый тип с входами
- **WHEN** задача имеет известный solver path и необходимые входные файлы на месте
- **THEN** вердикт `solvable` либо `uncertain`, но не `impossible`

#### Scenario: Неизвестный тип
- **WHEN** `task_type` неизвестен
- **THEN** вердикт не `impossible`, задача остаётся кандидатом универсального решателя

### Requirement: Impossible только по проверяемому доказательству
Система MUST выставлять `impossible` только при независимо проверяемом evidence: отсутствует обязательный вход, пустой требуемый `kb/`, coding без тестов или исходников, нечитаемый обязательный CSV, пустая инструкция, явное требование сети вне разрешённого LLM-прокси.

#### Scenario: Отсутствует обязательный вход
- **WHEN** инструкция ссылается на конкретный файл, которого нет в каталоге задачи
- **THEN** вердикт `impossible` с evidence о недостающем файле

#### Scenario: Слово impossible в тексте
- **WHEN** инструкция содержит слово `impossible`, но входы валидны
- **THEN** вердикт не `impossible`

### Requirement: Недоказанные сигналы не делают задачу невозможной
Unknown type, низкая уверенность модели, сложность, большой prompt, высокая оценка стоимости, низкий `P_solve` и самооценка LLM MUST NOT быть единственным основанием для `impossible`.

#### Scenario: Высокая оценка стоимости
- **WHEN** оценщик предсказывает большую стоимость, но структурных противоречий нет
- **THEN** задача остаётся `uncertain` или `solvable` и сравнивается planner по reward, P_solve, cost и времени

#### Scenario: Самооценка модели
- **WHEN** модель утверждает, что задача невыполнима, а независимого evidence нет
- **THEN** вердикт не `impossible`
