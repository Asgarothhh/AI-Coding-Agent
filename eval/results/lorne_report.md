## Caveats

- Lorne is an agent benchmark with tool calls; its per-task input includes history and tool output, which the competition coding solver may not send.
- The valid rows all come from one external model (`lmstudio/ornith-1.5-9b`); they are a weak prior, not evidence for the four allowed aliases.
- Zero/placeholder counters (for example `tokens_out = 1` on a 3k-token prompt) are rejected and reported, not replaced with zeros.
